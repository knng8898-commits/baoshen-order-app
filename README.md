# 寶神叫貨助手 v3

## 上傳到 GitHub Pages

1. 將此資料夾內所有檔案上傳到 `baoshen-order-app` 儲存庫根目錄。
2. 確認儲存庫中包含：
   - index.html
   - styles.css
   - data.js
   - app.js
   - manifest.json
   - service-worker.js
   - icons/
3. 等待 GitHub Pages 約 1～3 分鐘更新。
4. 開啟原本網址並重新整理。

## iPhone 安裝

Safari 開啟網站 → 分享 → 加入主畫面。
